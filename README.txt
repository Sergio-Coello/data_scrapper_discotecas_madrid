# AppLinkers

El programa recorre el calendario dinámico de AppLinkers y guarda diversos datos de los eventos (fecha, nombre de evento, ciudad, hora, precio, condiciones, edad minima, genero de musica) en cinco archivos CSV dentro de `datos_csv`: cuatro de discotecas especícifas (Fitz, Vandido, SAINT CLUB, JOY ESLAVA) y el ultimo con todas las demas ya que sino había muy pocos datos.

# Razon

Escogimos AppLinkers porque la mayoría de las páginas con información de discotecas tenian detectores de bots para que no se llenasen las listas gratuitas.
